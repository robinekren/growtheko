## Completeness rule

```txt
If a niche does not fit one of the 25 domains, it is not a new random category.
It must be mapped by asking:

1. What human driver does it serve?
2. Is it primarily money, body, identity, status, safety, knowledge, relationship, entertainment, place, object, or impact?
3. Which existing domain owns the audience?
4. Which market owns the monetization?
5. Which sub-market owns the trend source?

Only create a new top-level domain if all 25 fail.
```

## Scoring model

```txt
Trend Score = speed + emotion + visuality + audience size + monetization + content fit

Speed:
  Is it breaking now?

Emotion:
  Does it create pride, fear, greed, status, anger, hope, surprise?

Visuality:
  Can it become an image, reel, meme, graph, before/after, ranking?

Audience:
  Is the niche large enough or passionate enough?

Monetization:
  Can it lead to product, service, affiliate, ads, subscription, community?

Content fit:
  Can it become carousel, story, reel, short, newsletter, landing page?
```
