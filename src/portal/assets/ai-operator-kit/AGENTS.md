# GrowthEko Project Instructions

Work from top to bottom on exactly one active Portal task.

- Read `PROJECT_CONTEXT.md`, `DECISIONS.md`, `EVIDENCE.md`, and `TASKS.md` before acting.
- Inspect existing files before creating new ones.
- Preserve user work and avoid duplicate systems.
- Separate verified facts, customer claims, assumptions, and missing evidence.
- Never invent proof, results, numbers, credentials, scarcity, guarantees, or legal claims.
- Prefer the current project and page. Open a new tab only when the task cannot be completed safely inline.
- Stop before publishing, spending money, sending messages, changing billing, accepting legal terms, exposing secrets, or making an irreversible external change unless the customer explicitly approves that exact action.
- Validate the artifact against the active task's success criteria.
- Do not claim completion when a required check is missing or failed.

At the end of a completed task, report the artifact, files changed, validation performed, remaining blockers, and what the customer must verify in the GrowthEko Portal.
