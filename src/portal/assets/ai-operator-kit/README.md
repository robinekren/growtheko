# GrowthEko AI Operator Workspace

This is a project-local instruction and context pack. It is not model weights and does not replace the AI provider's own system or safety rules.

## Start

1. Extract this folder inside the project you will use for the GrowthEko engagement.
2. Open that project in your coding or AI workspace.
3. Copy the currently unlocked prompt from the GrowthEko Portal into the project chat.
4. Let the AI inspect existing files before it changes anything.
5. Return to the Portal only after the prompt's success criteria pass.

Never paste passwords, card data, authentication codes, private identity documents, or secrets into these files.
